# Правила работы с Kanban-доской

Неделя 1 · ведёт Мамаев Никита (Product Owner)

Карточки: [../kanban.csv](../kanban.csv) (импорт CSV в Jira или Trello).

## Колонки

| Колонка | Что значит | Кто переносит |
|---|---|---|
| **Backlog** | Задачи будущих недель | PO |
| **To Do (неделя)** | Взяты в текущую неделю на планировании | PO на планировании |
| **In Progress** | Исполнитель работает | исполнитель |
| **Review** | Готово, ждёт проверки: pull request или демонстрация | исполнитель |
| **Done** | Проверено и соответствует критериям готовности | проверяющий |

## Правила

- **WIP = 2**: у одного человека не больше двух карточек в In Progress.
- Карточку из Review в Done переносит не автор.
- Карточка с зависимостью (столбец «Depends on») не уходит в In Progress,
  пока зависимость не в Done. Исключение — работа на синтетике с той же схемой.
- Задержка больше дня — пометка «blocked» и сообщение в чат команды.

## Критерии готовности (Definition of Done)

- Код в ветке `main` через pull request, CI зелёный (ruff, pytest).
- Новая логика покрыта тестом.
- Если меняется схема данных или API, обновлены README и документация.
- Результат показан на еженедельном ревью.

## Ритм недели

| День | Встреча | Длительность |
|---|---|---|
| Понедельник | Планирование: карточки из Backlog → To Do | 30 мин |
| Ежедневно | Стендап: сделал / сделаю / мешает | 10 мин |
| Пятница | Ревью: показ результата + ретро | 45 мин |
